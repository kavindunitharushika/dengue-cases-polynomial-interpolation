# Polynomial Interpolation for Dengue Cases in Kandy District

## Project Overview
This academic project analyzes reported dengue cases in Kandy District, Sri Lanka, from 2014 to 2023 using numerical interpolation and approximation techniques.

The project applies mathematical methods and MATLAB to estimate dengue case values and compare them with actual reported data.

## Methods Used
- Newton's Divided Difference Interpolation
- Lagrange Interpolation
- Cubic Spline Interpolation
- Least Squares Approximation

## Tools and Technologies
- MATLAB
- Numerical Analysis
- Polynomial Interpolation
- Data Visualization

## Project Objectives
- Analyze historical dengue cases in Kandy District.
- Apply different interpolation and approximation methods.
- Compare estimated values with actual dengue cases.
- Visualize the results using MATLAB.
- Identify limitations of the mathematical models.

## Key Findings
The interpolation methods produced estimates that matched selected data points but showed significant differences from actual dengue cases in several years.

The study highlights the limitations of using polynomial interpolation and simple approximation methods to represent highly variable dengue case data.
